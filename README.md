# 🎸 Smart Adaptive Guitar Tab Generator V1

**An intelligent, local-first API and Web Interface for generating and overriding guitar tablatures.**

โปรเจกต์สร้างและสุ่มแทปกีตาร์อัจฉริยะที่ใช้สมองกลทางคณิตศาสตร์ (Greedy Pathfinding) ในการหาระยะการเคลื่อนที่ของนิ้วที่สั้นและลื่นไหลที่สุดบนคอกีตาร์ 24 เฟรต พร้อมระบบเรียนรู้พฤติกรรมผู้เล่น (AI Learning) เมื่อผู้ใช้ออกแบบการเล่นด้วยตัวเอง โปรเจกต์นี้ทำงานแบบ Local 100% ฟรี และรวดเร็ว

---

## ✨ Features (จุดเด่น)
- **🧠 Core Pathfinding Engine:** สร้างแทปกีตาร์แบบอัตโนมัติ 100% โดยคำนวณผ่านสมการระยะห่าง (Distance Cost) ของช่องเฟรตและสายกีตาร์
- **🎯 Dynamic Fret Boundaries:** กำหนดขอบเขต Fret Box ได้ตามใจชอบ เช่น บังคับเล่นเฉพาะ (เฟรต 5-9) หรือบังคับเล่นโหมด `Midi` เฉพาะ 4 สายล่าง
- **🎛️ Pitch Directives:** บังคับทิศทางเสียงแบบเด็ดขาดได้ด้วยตัวอักษรพิเศษ `^` (สูงกว่าโน้ตก่อนหน้า) และ `%` (ต่ำกว่าโน้ตก่อนหน้า) ไม่ว่าเส้นทางนั้นจะไกลแค่ไหนก็ตามระบบก็ทำให้เจอเสียงนั้น
- **📝 Interactive Tab Editor:** เบื่อตัวที่ระบบสุ่มให้? จิ้มแก้ตัวโน้ตดิบๆ บนหน้าโชว์แทปได้ทันที แล้วให้ระบบตีเส้นทางโน้ตตัวรั้งท้ายใหม่ทั้งหมดให้รับกับโน้ตที่เราแก้
- **🤖 AI Memory History:** ระบบจดจำสไตล์การเล่น เมื่อเราแก้ตัวโน้ตบ่อยๆ AI จะจำพิกัดตำแหน่งสุดแฮปปี้ของเราเพื่อมอบแต้มโบนัสในการสุ่มแทปครั้งถัดไปให้เข้ามือเราที่สุด ยิ่งสุ่มบ่อย ยิ่งแม่น
- **🖨️ Downloadable Tabs:** เอาข้อมูลตีเป็น Text อาร์ตๆ วาดแทปสายกีตาร์ให้สวยงาม พร้อมกด Download ออกเป็นไฟล์ `.txt` ไปแจกเพื่อนๆ ได้เลย
- **🚀 Ultra-Fast Server:** รันโครงสร้างทั้งหมดผ่าน FastAPI + Pydantic ความเร็วประมวลผลเสี้ยววินาที

## 🚀 Setup & Installation (วิธีติดตั้ง)

1. **เปิดโฟลเดอร์โปรเจกต์ (Terminal)** 
   ดาวน์โหลดโปรเจกต์ลงในเครื่องของคุณและเปิดหน้าต่าง Terminal ขึ้นมา

2. **เปิดระบบจำลอง Python (Virtual Environment):**
   ```powershell
   # สำหรับ Windows (PowerShell)
   .\venv\Scripts\Activate.ps1
   ```

3. **ติดตั้งไลบรารีที่จำเป็น (ถ้ายังไม่เคยลง):**
   ```powershell
   pip install -r requirements.txt
   ```

4. **Start the Engine (รันเซิร์ฟเวอร์):**
   ```powershell
   uvicorn api_main:app --reload
   ```

5. **Let's Play:**
   เข้าไปที่เว็บไซต์นี้ในเว็บบราวเซอร์ของคุณ: `http://127.0.0.1:8000/` เพื่อเริ่มบรรเลงเพลงได้เลย!

## 💻 How to play (วิธีใช้งานเบื้องต้น)
1. ในช่อง **Notes (comma separated):** พิมพ์ชื่อตัวโน้ตที่ต้องการกระซวกเรียงกันคั่นด้วยลูกน้ำ เช่น `C, D, E, F#, G^, C%`
2. **Start String / Fret:** ถ้าอยากบังคับจุดเริ่มต้นรันแทปตัวแรกให้พยุกต์เป็นพิกัดนี้ ก็กรอกสายกับเฟรตลงไป (สามารถเว้นว่างไว้ให้ AI สุ่มให้ได้)
3. **Fret Box:** กำหนดขอบเขตกรอบตั้งแต่ เฟรตที่กี่ ถึงเท่าไหร่
4. กดปุ่ม **Generate Tab!**
5. ต้องการแก้โน้ตตัวไหน? กดปุ่มลูกกลมๆ เรียงกันที่อยู่ตรงหมวด **Interactive Edit Mode** ด้านล่างแทป แล้วระบุสาย/เฟรตที่อยากจัดกระดูกใหม่เองได้เลย พร้อมระบบหน้าหลักโชว์ **AI Learning Dashboard** เพื่อดูว่า AI ท่องจำอะไรไปแล้วบ้าง!
